# Lumanara AI classes

This is a small React website built with Vite.

## Run it on your computer

Open Terminal and run these commands from the project folder:

```bash
cd ~/lum
npm install
npm run dev
```

Keep the terminal open. Click the local address Vite prints (usually `http://localhost:5173`) or copy it into your browser. Stop the website with `Ctrl+C` in the terminal.

`index.html` is the page entry point, not a terminal command. The React components are in `src/App.jsx` and the design is in `src/style.css`.

## Deploy on Vercel

1. Upload this project to a GitHub repository.
2. In Vercel, select **Add New → Project** and import the repository.
3. Vercel detects Vite automatically. Choose **Deploy**.
4. To connect your purchased domain, open the Vercel project’s **Settings → Domains**, add your domain, then enter the DNS records Vercel shows in your registrar’s DNS settings.

Update the contact email (`hello@lumanara.com`) in `src/App.jsx` before publishing. Vercel’s [custom domain guide](https://vercel.com/docs/domains/set-up-custom-domain) has current DNS instructions.
